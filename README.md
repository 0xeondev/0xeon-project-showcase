# 0xEon / Infinity Energy

An experimental browser universe for Season 0. Explore the Infinity Energy
world, connect an account with a wallet signature, and follow a transparent
testnet ledger on Base Sepolia.

0xEon is built for testnet review and careful iteration. It is not a mainnet
launch, and it does not promise future token value.

## Features

- **Responsive, multilingual interface** for the Infinity Energy world on
  desktop and mobile.
- **Wallet-based identity** using signature challenges. 0xEon never asks for a
  seed phrase or private key.
- **Account-bound cloud saves** with revision checks and multiple save slots.
- **Server-authoritative internal points** and leaderboard foundations.
- **Public testnet ledger** of Base Sepolia transfers, backed by verified
  contract events.
- **Testnet faucet** protected by Turnstile, with cooldowns, daily and lifetime
  limits, and an operational pause control.
- **Reviewable release process** with security-focused tests and rehearsed
  recovery procedures.

## Testnet-only boundaries

- Season 0 runs on testnet only.
- In-game points are internal accounting units. They are not INF tokens, they
  are not transferable, and they do not guarantee any future claim or reward.
- Base Sepolia transfers are testnet activity and have no mainnet value.
- The game is a simulation and is not a promise of monetary value.
- 0xEon is not presented as independently audited, and it is not
  mainnet-ready. Testnet status does not make the system risk-free.

Read the [risk disclaimer](https://0xeon.com/risk-disclaimer.html) before
using the faucet or the game.

## Security

Wallet flows only request signatures. Never share a private key, seed phrase,
password, session cookie, or API token with anyone claiming to represent 0xEon.

To report a vulnerability privately, follow the contact details in
[security.txt](https://0xeon.com/.well-known/security.txt) or use the
[support page](https://0xeon.com/support.html). Please do not open public
issues that contain credentials, private data, or exploit details.
